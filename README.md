## 📖 About The Project

VANTA Motorcycles is a modern, visually immersive Cafe Racer website concept inspired by premium motorcycle brands and cinematic automotive campaigns.

The project focuses on creating a distinctive digital experience with dramatic motorcycle imagery, minimal layouts, refined typography, and smooth interactions.

Rather than relying on conventional card-based layouts, the website emphasizes visual storytelling, full-width imagery, and an editorial design approach.

## ✨ Features

- 🏍️ **Premium Cafe Racer Aesthetic** — A bold, dark automotive-inspired visual identity.
- 🎬 **Cinematic Hero Section** — Large-scale visuals and impactful typography.
- 🖤 **Modern Dark Theme** — A sophisticated combination of dark backgrounds, metallic tones, and high-contrast text.
- 🌀 **Smooth Animations** — Fluid transitions and motion effects for an immersive browsing experience.
- 📱 **Responsive Design** — Adaptable layouts for desktop, tablet, and mobile devices.
- 🎨 **Editorial Layout** — Minimal UI, generous whitespace, and image-focused storytelling.
- ⚡ **Fast Development & Build** — Powered by Vite and a modern React toolchain.
- 🧭 **Intuitive Navigation** — Clean navigation designed for a seamless user experience.

## 📸 Design Philosophy

**Dark. Minimal. Mechanical. Cinematic.**

The visual direction takes inspiration from luxury automotive campaigns and custom motorcycle culture.

- **Color Palette:** Matte black, charcoal, metallic silver, off-white, and subtle accent tones.
- **Typography:** Bold, oversized headlines paired with clean, modern supporting text.
- **Imagery:** Dramatic motorcycle photography, atmospheric lighting, and detailed mechanical aesthetics.
- **Interactions:** Smooth scrolling, subtle motion, and refined hover effects.
- **Layout:** Immersive full-screen sections and minimal interface elements.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Swastik99-git/cafe-racer.git
```

### 2. Navigate to the Project

```bash
cd cafe-racer
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```

## 🌍 Deployment

This project is deployed on **Vercel**.

### Deploy Your Own

1. Fork or clone this repository.
2. Import the repository into [Vercel](https://vercel.com/).
3. Select **Vite** as the framework preset.
4. Configure the build settings:

   | Setting | Value |
   |---|---|
   | Framework | Vite |
   | Build Command | `npm run build` |
   | Output Directory | `dist` |
   | Install Command | `npm install` |

5. Add environment variables only if your project requires them.
6. Click **Deploy**.

Your website will be live once the deployment completes successfully.
